About this project

One person. Primary sources. No invented requirements.

RunOnVPS is independently maintained by one person. It exists to answer a practical question before you buy or resize a server: what does this self-hosted app actually need?

One-person maintenance statement

RunOnVPS is researched, built and maintained by one individual. There is no team of reviewers behind the scenes. Corrections may take time, but the method is deliberately narrow and auditable: one app, one checked source, one clearly labelled result.

The project is independent and is not the official website of any app or VPS provider listed here.

How the data was checked

The first dataset was assembled on 24 October 2026 from each project’s GitHub repository, official documentation or official installation material. For every app we recorded its repository, licence, GitHub stars, Docker support, GPU notes, documented minimum and recommended figures, a commercial alternative, source URL and source notes.

  • Official means the value appeared in the dataset without an estimate marker and was attributed to the checked project source.
  • Estimated means the source did not publish that complete hardware figure. We made a conservative estimate from the documented default Docker deployment and marked the value in the source data.
  • Not stated means the current page dataset has no usable value for that field.

An estimate is never rewritten as an official requirement. Source notes are reproduced on each app page so you can see important qualifications — for example, when a value covers only part of a stack, when a project has multiple editions, or when user files are excluded from a disk figure.

How to use the recommendations

Minimum means “recorded as the floor in the checked data,” not a promise of good performance. Recommended is the safer starting point for a real deployment. Our suggested VPS tier is derived mechanically from recommended RAM: up to 1 GB maps to a 1 GB tier, then 2 GB, 4 GB, 8 GB, and above 8 GB maps to a 16 GB tier.

Real usage can move you up a tier. Media libraries, OCR, machine learning, transcoding, plug-ins, traffic spikes, backups and running several services together all matter. Use the calculator for a first total, then leave headroom for the operating system and peaks.

Corrections

Requirements change as software changes. If a project publishes a new official minimum or you spot a mismatch between a page and its linked source, the source should win until the page is corrected. Each app page links to both the source used for the check and the project repository.
