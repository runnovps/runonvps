Verdict

The short version

  • Umami is lighter in our dataset, but every Umami hardware figure is an estimate: its README publishes only software requirements (Node.js 18.18+ and PostgreSQL 12.14+).
  • Plausible’s 2 GB RAM minimum is official; its CPU and disk rows are estimates, and its disk needs grow with the ClickHouse event data you retain.
  • The licence differs: Plausible is AGPL-3.0, Umami is MIT.
  • Both position themselves as privacy-first Google Analytics alternatives with official Docker deployments. Umami has more GitHub stars in our dataset (~39.6k vs ~29.4k, checked 2026-10-24).

Neither verdict nor table scores the apps against each other — the right pick depends on the job, the licence you can accept, and how much of the spec is published rather than estimated. If you plan to run either alongside other apps, add it to a multi-app VPS estimate →
