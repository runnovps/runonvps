Quick start

Docker Compose quick start

A trimmed quick-start version of the official Healthchecks Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
# Official two-service stack; copy docker/.env.example to docker/.env and set SECRET_KEY, SITE_ROOT and ALLOWED_HOSTS first.
services:
  db:
    image: postgres:16
    restart: unless-stopped
    environment:
      POSTGRES_PASSWORD: "${POSTGRES_PASSWORD:?Set POSTGRES_PASSWORD in .env}"
      POSTGRES_USER: ${POSTGRES_USER:-healthchecks}
      POSTGRES_DB: ${POSTGRES_DB:-healthchecks}
    volumes:
      - hc-data:/var/lib/postgresql/data
  web:
    image: healthchecks/healthchecks:latest
    restart: unless-stopped
    depends_on: [db]
    ports:
      - "8000:8000"
    environment:
      - SECRET_KEY=${SECRET_KEY:?Set SECRET_KEY in .env}
      - SITE_ROOT=${SITE_ROOT:?Set SITE_ROOT in .env}
      - ALLOWED_HOSTS=${ALLOWED_HOSTS:?Set ALLOWED_HOSTS in .env}
      - DEFAULT_FROM_EMAIL=${DEFAULT_FROM_EMAIL:-healthchecks@example.org}
      - EMAIL_HOST=${EMAIL_HOST:-localhost}
    volumes:
      - hc-static:/opt/healthchecks/static-collected

volumes:
  hc-data:
  hc-static:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Healthchecks VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Healthchecks?

In the RunOnVPS dataset, Healthchecks needs at least RAM 2 GB, CPU 1 vCPU, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does Healthchecks need a GPU?

No. Healthchecks does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Healthchecks replace?

Healthchecks is catalogued here as a self-hosted alternative to Cronitor / Dead Man's Snitch. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
