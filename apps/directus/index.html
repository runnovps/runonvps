Quick start

Docker Compose quick start

A trimmed quick-start version of the official Directus Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  database:
    image: postgis/postgis:17-3.5
    restart: unless-stopped
    volumes:
      - ./data/database:/var/lib/postgresql/data
    environment:
      POSTGRES_USER: "${POSTGRES_USER:-directus}"
      POSTGRES_PASSWORD: "${POSTGRES_PASSWORD:?Set in .env}"
      POSTGRES_DB: "${POSTGRES_DB:-directus}"
    healthcheck:
      test: ["CMD", "pg_isready", "--host=localhost", "--username=directus"]
      interval: 10s
      timeout: 5s
      retries: 5
  cache:
    image: redis:7
    restart: unless-stopped
    healthcheck:
      test: ["CMD-SHELL", "[ $$(redis-cli ping) = 'PONG' ]"]
      interval: 10s
      timeout: 5s
      retries: 5
  directus:
    image: directus/directus:${DIRECTUS_VERSION:-latest}
    restart: unless-stopped
    ports:
      - "${DIRECTUS_PORT:-8055}:8055"
    volumes:
      - ./uploads:/directus/uploads
      - ./extensions:/directus/extensions
    depends_on:
      database:
        condition: service_healthy
      cache:
        condition: service_healthy
    environment:
      SECRET: "${DIRECTUS_SECRET:?Set in .env}"
      DB_CLIENT: "pg"
      DB_HOST: "database"
      DB_PORT: "5432"
      DB_DATABASE: "${POSTGRES_DB:-directus}"
      DB_USER: "${POSTGRES_USER:-directus}"
      DB_PASSWORD: "${POSTGRES_PASSWORD:?Set in .env}"
      CACHE_ENABLED: "true"
      CACHE_STORE: "redis"
      REDIS: "redis://cache:6379"
      ADMIN_EMAIL: "${DIRECTUS_ADMIN_EMAIL:?Set in .env}"
      ADMIN_PASSWORD: "${DIRECTUS_ADMIN_PASSWORD:?Set in .env}"
      PUBLIC_URL: "${DIRECTUS_PUBLIC_URL:-http://localhost:8055}"
volumes:
  database:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Directus VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Directus?

In the RunOnVPS dataset, Directus needs at least RAM 1 GB, CPU 1 vCPU, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does Directus need a GPU?

No. Directus does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Directus replace?

Directus is catalogued here as a self-hosted alternative to Directus Cloud / Contentful. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
