FAQ

Komga VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Komga?

In the RunOnVPS dataset, Komga needs at least RAM 1GB, CPU 1, disk 5GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does Komga need a GPU?

No. Komga does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Komga replace?

Komga is catalogued here as a self-hosted alternative to comiXology (Kindle). Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Official documentation publishes no minimum hardware — 官方未标明，均为估算; the official Docker page notes the Java process is by default limited to a maximum of usually 1GB of memory (adjustable via JAVA_TOOL_OPTIONS=-Xmx), which anchors the RAM estimate for this JVM app. The /config folder must be on a local filesystem, not a network share, per official docs. Disk scales with the comics library and thumbnails, excluded from the estimate baseline.
