Quick start

Docker Compose quick start

A trimmed quick-start version of the official BookStack Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  bookstack:
    image: lscr.io/linuxserver/bookstack:latest
    restart: unless-stopped
    depends_on: [bookstack-db]
    ports:
      - "${BOOKSTACK_PORT:-6875}:80"
    environment:
      APP_URL: "${APP_URL:?Set APP_URL in .env}"
      APP_KEY: "${APP_KEY:?Set APP_KEY in .env}"
      DB_HOST: bookstack-db
      DB_DATABASE: ${DB_DATABASE:-bookstack}
      DB_USERNAME: ${DB_USERNAME:-bookstack}
      DB_PASSWORD: "${DB_PASSWORD:?Set DB_PASSWORD in .env}"
    volumes:
      - ./data/config:/config
  bookstack-db:
    image: lscr.io/linuxserver/mariadb:latest
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: "${MYSQL_ROOT_PASSWORD:?Set in .env}"
      MYSQL_DATABASE: ${DB_DATABASE:-bookstack}
      MYSQL_USER: ${DB_USERNAME:-bookstack}
      MYSQL_PASSWORD: "${DB_PASSWORD:?Set DB_PASSWORD in .env}"
    volumes:
      - ./data/db:/config

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

BookStack VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for BookStack?

In the RunOnVPS dataset, BookStack needs at least RAM 1 GB, CPU 1 vCPU, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does BookStack need a GPU?

No. BookStack does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does BookStack replace?

BookStack is catalogued here as a self-hosted alternative to Confluence / Notion. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Official installation docs (bookstackapp.com/docs/admin/installation) state software requirements only (PHP >= 8.2; MySQL >= 8.0 or MariaDB >= 10.6), no hardware minimum (checked 2026-10-24); official site says it can run happily on a 2.50 GBP IONOS VPS. Docker setups listed in the official docs are community-maintained (LinuxServer.io, solidnerd); no first-party image. GitHub repo banner says the project is now managed on Codeberg; GitHub address kept as requested. Stars approximate as of 2026-10-24.
