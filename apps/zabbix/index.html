Quick start

Docker Compose quick start

A trimmed quick-start version of the official Zabbix Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  mysql-server:
    image: mysql:8.0
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: "${MYSQL_ROOT_PASSWORD:?Set MYSQL_ROOT_PASSWORD in .env}"
      MYSQL_USER: zabbix
      MYSQL_PASSWORD: "${MYSQL_PASSWORD:?Set MYSQL_PASSWORD in .env}"
      MYSQL_DATABASE: zabbix
    command:
      - --character-set-server=utf8mb4
      - --collation-server=utf8mb4_bin
    volumes:
      - ./mysql:/var/lib/mysql
  zabbix-server-mysql:
    image: zabbix/zabbix-server-mysql:alpine-7.4-latest
    restart: unless-stopped
    ports:
      - "10051:10051"
    environment:
      DB_SERVER_HOST: mysql-server
      MYSQL_USER: zabbix
      MYSQL_PASSWORD: "${MYSQL_PASSWORD:?Set MYSQL_PASSWORD in .env}"
      MYSQL_DATABASE: zabbix
    depends_on:
      - mysql-server
  zabbix-web-nginx-mysql:
    image: zabbix/zabbix-web-nginx-mysql:alpine-7.4-latest
    restart: unless-stopped
    ports:
      - "8080:8080"
    environment:
      ZBX_SERVER_HOST: zabbix-server-mysql
      DB_SERVER_HOST: mysql-server
      MYSQL_USER: zabbix
      MYSQL_PASSWORD: "${MYSQL_PASSWORD:?Set MYSQL_PASSWORD in .env}"
      MYSQL_DATABASE: zabbix
      PHP_TZ: ${TZ:-UTC}
    depends_on:
      - mysql-server
      - zabbix-server-mysql

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Zabbix VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Zabbix?

In the RunOnVPS dataset, Zabbix needs at least RAM 8 GiB, CPU 2 vCPU, disk 20 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 16 GB RAM tier.

Does Zabbix need a GPU?

No. Zabbix does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Zabbix replace?

Zabbix is catalogued here as a self-hosted alternative to Datadog / PRTG. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Official Requirements page (checked 2026-11-17): sizing table Small (1,000 metrics) 2 cores/8 GiB, Medium (10,000) 4 cores/16 GiB, Large (100,000) 16 cores/64 GiB, Very large (1,000,000) 32 cores/96 GiB — min/rec use the Small/Medium rows. Official docs give no fixed disk figure (history storage 'at least a couple of gigabytes', scales with hosts, parameters and retention), so min_disk is an estimate excluding monitored data; large installs should run the database on a separate server. Official Docker deployment via zabbix/zabbix-docker (zabbix-server-mysql + zabbix-web-nginx-mysql + MySQL, web on 8080, server port 10051); default web login Admin/zabbix must be changed.
