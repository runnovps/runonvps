Quick start

Docker Compose quick start

A trimmed quick-start version of the official Ghost Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  ghost:
    image: ghost:6-alpine
    restart: unless-stopped
    depends_on: [mysql]
    ports:
      - "${GHOST_PORT:-2368}:2368"
    environment:
      database__client: mysql
      database__connection__host: mysql
      database__connection__user: ${MYSQL_USER:-ghost}
      database__connection__password: "${MYSQL_PASSWORD:?Set in .env}"
      database__connection__database: ${MYSQL_DATABASE:-ghost}
      url: ${GHOST_URL:-http://localhost:2368}
    volumes:
      - ghost_content:/var/lib/ghost/content
  mysql:
    image: mysql:8.0
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: "${MYSQL_ROOT_PASSWORD:?Set in .env}"
      MYSQL_PASSWORD: "${MYSQL_PASSWORD:?Set in .env}"
      MYSQL_DATABASE: ${MYSQL_DATABASE:-ghost}
      MYSQL_USER: ${MYSQL_USER:-ghost}
    volumes:
      - mysql_data:/var/lib/mysql
volumes:
  ghost_content:
  mysql_data:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Ghost VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Ghost?

In the RunOnVPS dataset, Ghost needs at least RAM 1GB, CPU 1, disk 10GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does Ghost need a GPU?

No. Ghost does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Ghost replace?

Ghost is catalogued here as a self-hosted alternative to Substack. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
