Quick start

Docker Compose quick start

A trimmed quick-start version of the official Docmost Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
# Official three-service stack; APP_SECRET must be at least 32 characters.
services:
  docmost:
    image: docmost/docmost:latest
    restart: unless-stopped
    depends_on:
      - db
      - redis
    ports:
      - "127.0.0.1:3000:3000"
    environment:
      APP_URL: ${APP_URL:-http://localhost:3000}
      APP_SECRET: CHANGE_ME_GENERATE_WITH_OPENSSL_RAND_HEX_32
      DATABASE_URL: postgresql://docmost:CHANGE_ME@db:5432/docmost
      REDIS_URL: redis://redis:6379
    volumes:
      - docmost:/app/data/storage
  db:
    image: postgres:18
    restart: unless-stopped
    environment:
      POSTGRES_DB: docmost
      POSTGRES_USER: docmost
POSTGRES_PASSWORD: <redacted>
    volumes:
      - db_data:/var/lib/postgresql
  redis:
    image: redis:8
    restart: unless-stopped
    command: ["redis-server", "--appendonly", "yes", "--maxmemory-policy", "noeviction"]
    volumes:
      - redis_data:/data
volumes:
  docmost:
  db_data:
  redis_data:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Docmost VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Docmost?

In the RunOnVPS dataset, Docmost needs at least RAM 2 GB, CPU 1 vCPU, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does Docmost need a GPU?

No. Docmost does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Docmost replace?

Docmost is catalogued here as a self-hosted alternative to Confluence / Notion. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
