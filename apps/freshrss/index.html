Quick start

Docker Compose quick start

A trimmed quick-start version of the official FreshRSS Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  freshrss:
    image: freshrss/freshrss:latest
    restart: unless-stopped
    ports:
      - "${FRESHRSS_PORT:-8080}:80"
    environment:
      TZ: ${TZ:-UTC}
      CRON_MIN: ${CRON_MIN:-15}
    volumes:
      - ./data:/var/www/FreshRSS/data
      - ./extensions:/var/www/FreshRSS/extensions

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

FreshRSS VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for FreshRSS?

In the RunOnVPS dataset, FreshRSS needs at least RAM 512MB, CPU 1, disk 5GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 1 GB RAM tier.

Does FreshRSS need a GPU?

No. FreshRSS does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does FreshRSS replace?

FreshRSS is catalogued here as a self-hosted alternative to Feedly. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
