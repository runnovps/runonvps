Quick start

Docker Compose quick start

A trimmed quick-start version of the official Homarr Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  homarr:
    image: ghcr.io/homarr-labs/homarr:latest
    container_name: homarr
    restart: unless-stopped
    environment:
      - SECRET_ENCRYPTION_KEY=${HOMARR_SECRET_ENCRYPTION_KEY}
    ports:
      - "${HOMARR_PORT:-7575}:7575"
    volumes:
      - ./appdata:/appdata

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Homarr VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Homarr?

In the RunOnVPS dataset, Homarr needs at least RAM 512 MB, CPU 1 vCPU, disk 2 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does Homarr need a GPU?

No. Homarr does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Homarr replace?

Homarr is catalogued here as a self-hosted alternative to Start.me. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
