Quick start

Docker Compose quick start

A trimmed quick-start version of the official Open WebUI Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  ollama:
    image: ollama/ollama:${OLLAMA_DOCKER_TAG:-latest}
    restart: unless-stopped
    tty: true
    volumes:
      - ollama:/root/.ollama
  open-webui:
    image: ghcr.io/open-webui/open-webui:${WEBUI_DOCKER_TAG:-main}
    restart: unless-stopped
    depends_on: [ollama]
    ports:
      - "${OPEN_WEBUI_PORT:-3000}:8080"
    environment:
      - OLLAMA_BASE_URL=http://ollama:11434
      - WEBUI_SECRET_KEY=${WEBUI_SECRET_KEY:?Set WEBUI_SECRET_KEY in .env}
    volumes:
      - open-webui:/app/backend/data
    extra_hosts:
      - host.docker.internal:host-gateway
volumes:
  ollama:
  open-webui:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Open WebUI VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Open WebUI?

In the RunOnVPS dataset, Open WebUI needs at least RAM 2 GB, CPU 1 vCPU, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does Open WebUI need a GPU?

Not for the baseline deployment. A GPU is optional for Open WebUI and only helps specific workloads — see the source notes on this page.

What SaaS product does Open WebUI replace?

Open WebUI is catalogued here as a self-hosted alternative to ChatGPT. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
