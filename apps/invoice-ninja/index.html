Quick start

Docker Compose quick start

A trimmed quick-start version of the official Invoice Ninja Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  server:
    image: nginx
    restart: always
    env_file: [.env]
    volumes:
      - ./config/nginx/in-vhost.conf:/etc/nginx/conf.d/in-vhost.conf:ro
      - ./docker/app/public:/var/www/app/public:ro
    depends_on: [app]
    ports:
      - "80:80"
  app:
    image: invoiceninja/invoiceninja:5
    restart: always
    env_file: [.env]
    volumes:
      - ./docker/app/public:/var/www/app/public:rw
      - ./docker/app/storage:/var/www/app/storage:rw
    depends_on: [db]
  db:
    image: mysql:8
    restart: always
    env_file: [.env]
    volumes:
      - ./docker/mysql/data:/var/lib/mysql:rw

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Invoice Ninja VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Invoice Ninja?

In the RunOnVPS dataset, Invoice Ninja needs at least RAM 1 GB, CPU 1 vCPU, disk 5 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does Invoice Ninja need a GPU?

No. Invoice Ninja does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Invoice Ninja replace?

Invoice Ninja is catalogued here as a self-hosted alternative to Invoice Ninja Cloud / FreshBooks. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
