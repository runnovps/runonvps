Quick start

Docker Compose quick start

A trimmed quick-start version of the official Prometheus Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
# Requires a prometheus.yml beside this file — the official first-steps guide ships a sample config that scrapes Prometheus itself on localhost:9090.
services:
  prometheus:
    image: prom/prometheus:latest
    restart: unless-stopped
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
      - prometheus-data:/prometheus
volumes:
  prometheus-data:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Prometheus VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Prometheus?

In the RunOnVPS dataset, Prometheus needs at least RAM 1 GB, CPU 1 vCPU, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does Prometheus need a GPU?

No. Prometheus does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Prometheus replace?

Prometheus is catalogued here as a self-hosted alternative to Grafana Cloud / Datadog. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
