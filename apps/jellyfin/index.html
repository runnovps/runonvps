Quick start

Docker Compose quick start

A trimmed quick-start version of the official Jellyfin Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  jellyfin:
    image: jellyfin/jellyfin:latest
    restart: unless-stopped
    ports:
      - "8096:8096"
      - "7359:7359/udp"
    environment:
      TZ: ${TZ:-UTC}
    volumes:
      - ./data/config:/config
      - ./data/cache:/cache
      - ./media:/media

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Jellyfin VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Jellyfin?

In the RunOnVPS dataset, Jellyfin needs at least RAM 4GB, CPU 2, disk 100GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 8 GB RAM tier.

Does Jellyfin need a GPU?

Not for the baseline deployment. A GPU is optional for Jellyfin and only helps specific workloads — see the source notes on this page.

What SaaS product does Jellyfin replace?

Jellyfin is catalogued here as a self-hosted alternative to Plex. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Stars/license checked 2026-10-24 on the GitHub repo page. Official Hardware Selection page publishes recommended specs only, no hard minimum — 官方未标明最低配置: it recommends 8GB RAM for an average deployment (rec_ram official) and notes 4GB may be sufficient for a Linux server without a GUI (used as min_ram), plus a 100GB SSD for OS, Jellyfin files and transcoding cache (min_disk is that official recommendation, media library excluded). Official CPU guidance is by model class (e.g. Intel N100 / Core i5-11400 with integrated graphics; a modern CPU with 4 threads can handle the workload when hardware acceleration is used), so core counts are estimates; x86 CPUs must support SSE4.1 from Jellyfin 10.11. GPU is not required but the docs say running without one is NOT recommended because CPU transcoding is very demanding; Intel integrated graphics is the recommended path. Official Docker install is provided.
