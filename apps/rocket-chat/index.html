Quick start

Docker Compose quick start

A trimmed quick-start version of the official Rocket.Chat Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  rocketchat:
    image: registry.rocket.chat/rocketchat/rocket.chat:${RELEASE:-8.0.1}
    restart: always
    environment:
      ROOT_URL: ${ROOT_URL:-http://localhost:3000}
      PORT: 3000
      MONGO_URL: mongodb://mongodb:27017/rocketchat?replicaSet=rs0
    ports:
      - "3000:3000"
    depends_on: [mongodb, mongodb-init]
  mongodb:
    image: docker.io/mongodb/mongodb-community-server:${MONGODB_VERSION:-8.2}-ubi8
    restart: always
    command: mongod --replSet rs0 --bind_ip_all
    volumes:
      - ./mongodb_data:/data/db
  mongodb-init:
    image: docker.io/mongodb/mongodb-community-server:${MONGODB_VERSION:-8.2}-ubi8
    restart: on-failure
    depends_on: [mongodb]
    entrypoint: |
      sh -xc '
        until mongosh "mongodb://mongodb:27017/?directConnection=true" --eval "db.adminCommand(\"ping\")" >/dev/null 2>&1; do sleep 5; done;
        mongosh "mongodb://mongodb:27017/?directConnection=true" --eval "rs.initiate({_id: \"rs0\", members: [{ _id: 0, host: \"mongodb:27017\" }]})";
      '

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Rocket.Chat VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Rocket.Chat?

In the RunOnVPS dataset, Rocket.Chat needs at least RAM 4 GB, CPU 2 vCPU, disk 20 GB. Our suggested starting tier, based on the recommended RAM, is the 8 GB RAM tier.

Does Rocket.Chat need a GPU?

No. Rocket.Chat does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Rocket.Chat replace?

Rocket.Chat is catalogued here as a self-hosted alternative to Slack. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Official system requirements (checked 2026-11-12, Rocket.Chat 8.x): Starter scenario (up to 500 concurrent users) minimum 2 vCPU, 4 GiB RAM, 20 GiB storage for the Rocket.Chat server (MongoDB separately 2 vCPU/4 GiB/10 GiB); larger workspaces 4 vCPU, 8-12 GiB RAM. Official Docker deployment via the rocketchat-compose repo: image registry.rocket.chat/rocketchat/rocket.chat, MongoDB mongodb-community-server 8.x-ubi8 with replica set rs0, web UI on port 3000.
