FAQ

PhotoPrism VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for PhotoPrism?

In the RunOnVPS dataset, PhotoPrism needs at least RAM 3GB, CPU 2, disk 10GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does PhotoPrism need a GPU?

Not for the baseline deployment. A GPU is optional for PhotoPrism and only helps specific workloads — see the source notes on this page.

What SaaS product does PhotoPrism replace?

PhotoPrism is catalogued here as a self-hosted alternative to Google Photos. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Stars checked 2026-10-24 on the GitHub repo page; the README license badge is AGPL-3.0 while GitHub repo metadata shows License: Other (NOASSERTION). Official Setup page: host on a server with at least 2 cores and 3GB of physical memory (min official), at least 4GB of swap configured, no hard memory limit, local SSD recommended for database and cache; the official Quickstart recommends 4GB of physical memory (rec_ram). Official docs give no fixed disk size — min_disk is an estimate excluding the photo/video library. GPU is optional (a compose.nvidia.yaml variant is shipped for TensorFlow acceleration). Docker Compose is the recommended install.
