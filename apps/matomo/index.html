FAQ

Matomo VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Matomo?

In the RunOnVPS dataset, Matomo needs at least RAM 1 GB, CPU 1 vCPU, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does Matomo need a GPU?

No. Matomo does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Matomo replace?

Matomo is catalogued here as a self-hosted alternative to Google Analytics. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Source check

Important notes

Official requirements page (matomo.org/docs/requirements, checked 2026-10-25) gives a minimum recommended configuration for tracking 100,000 pageviews/month or less: 2 CPU, 2 GB RAM, 50 GB SSD disk, one server for app+database; Matomo 6 requires PHP 8.1+ and MySQL 8.0+/MariaDB 10.6+. No bare minimum is published, so minimum values are conservative estimates for a small single-site install. Official Docker image matomo exists on Docker Hub. GitHub stars 21980 on 2026-10-25.
