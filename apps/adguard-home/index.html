Quick start

Docker Compose quick start

A trimmed quick-start version of the official AdGuard Home Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  adguardhome:
    image: adguard/adguardhome:latest
    restart: unless-stopped
    ports:
      - "53:53/tcp"
      - "53:53/udp"
      - "${ADGUARD_WEB_PORT:-3000}:3000/tcp"
    volumes:
      - ./work:/opt/adguardhome/work
      - ./conf:/opt/adguardhome/conf

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

AdGuard Home VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for AdGuard Home?

In the RunOnVPS dataset, AdGuard Home needs at least RAM 512MB, CPU 1, disk 5GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 1 GB RAM tier.

Does AdGuard Home need a GPU?

No. AdGuard Home does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does AdGuard Home replace?

AdGuard Home is catalogued here as a self-hosted alternative to NextDNS. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
