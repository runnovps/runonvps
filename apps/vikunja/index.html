Quick start

Docker Compose quick start

A trimmed quick-start version of the official Vikunja Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  vikunja:
    image: vikunja/vikunja
    restart: unless-stopped
    environment:
      - VIKUNJA_SERVICE_PUBLICURL=${VIKUNJA_PUBLIC_URL:-http://localhost:3456}
    ports:
      - "${VIKUNJA_PORT:-3456}:3456"
    volumes:
      - ./files:/app/vikunja/files
      - ./db:/db

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Vikunja VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Vikunja?

In the RunOnVPS dataset, Vikunja needs at least RAM 512 MB, CPU 1 vCPU, disk 2 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 1 GB RAM tier.

Does Vikunja need a GPU?

No. Vikunja does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Vikunja replace?

Vikunja is catalogued here as a self-hosted alternative to Todoist / Asana. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
