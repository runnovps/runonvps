Quick start

Docker Compose quick start

A trimmed version of the SearXNG file from our Self-host Starter Pack — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  searxng:
    image: searxng/searxng:latest
    container_name: searxng
    restart: unless-stopped
    ports:
      - "${SEARXNG_PORT:-8080}:8080"
    volumes:
      - ./searxng:/etc/searxng
    environment:
      - BASE_URL=http://localhost:8080/
      - INSTANCE_NAME=searxng

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The pack version adds per-app setup notes, backup pointers and hardening checks.

FAQ

SearXNG VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for SearXNG?

In the RunOnVPS dataset, SearXNG needs at least RAM 1 GB, CPU 1 vCPU, disk 5 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does SearXNG need a GPU?

No. SearXNG does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does SearXNG replace?

SearXNG is catalogued here as a self-hosted alternative to Google / DuckDuckGo. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
