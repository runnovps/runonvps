Quick start

Docker Compose quick start

A trimmed quick-start version of the official LibreChat Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  api:
    image: registry.librechat.ai/librechat-ai/librechat-dev:latest
    restart: unless-stopped
    ports:
      - "${PORT:-3080}:${PORT:-3080}"
    depends_on: [mongodb, rag_api]
    user: "${UID:-1000}:${GID:-1000}"
    extra_hosts:
      - host.docker.internal:host-gateway
    environment:
      - HOST=0.0.0.0
      - MONGO_URI=mongodb://mongodb:27017/LibreChat
      - MEILI_HOST=http://meilisearch:7700
      - RAG_PORT=${RAG_PORT:-8000}
      - RAG_API_URL=http://rag_api:${RAG_PORT:-8000}
    volumes:
      - ./.env:/app/.env
      - ./images:/app/client/public/images
      - ./uploads:/app/uploads
      - ./logs:/app/logs
      - librechat-data:/app/data
  mongodb:
    image: mongo:8.0.20
    restart: unless-stopped
    user: "${UID:-1000}:${GID:-1000}"
    volumes:
      - ./data-node:/data/db
    command: mongod --noauth
  meilisearch:
    image: getmeili/meilisearch:v1.35.1
    restart: unless-stopped
    user: "${UID:-1000}:${GID:-1000}"
    environment:
      - MEILI_HOST=http://meilisearch:7700
      - MEILI_NO_ANALYTICS=true
      - MEILI_MASTER_KEY=${MEILI_MASTER_KEY:?Set MEILI_MASTER_KEY in .env}
    volumes:
      - ./meili_data_v1.35.1:/meili_data
  vectordb:
    image: pgvector/pgvector:0.8.0-pg15-trixie
    restart: unless-stopped
    environment:
      POSTGRES_DB: ${POSTGRES_DB:-mydatabase}
      POSTGRES_USER: ${POSTGRES_USER:-myuser}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:?Set POSTGRES_PASSWORD in .env}
    volumes:
      - pgdata2:/var/lib/postgresql/data
  rag_api:
    image: registry.librechat.ai/librechat-ai/librechat-rag-api-dev-lite:latest
    restart: unless-stopped
    depends_on: [vectordb]
    env_file: [.env]
    environment:
      - DB_HOST=vectordb
      - RAG_PORT=${RAG_PORT:-8000}
volumes:
  pgdata2:
  librechat-data:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

LibreChat VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for LibreChat?

In the RunOnVPS dataset, LibreChat needs at least RAM 1 GiB, CPU 1 vCPU. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does LibreChat need a GPU?

No. LibreChat does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does LibreChat replace?

LibreChat is catalogued here as a self-hosted alternative to ChatGPT. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Minimum is official (docs: LibreChat's containers need at least 1 GiB RAM and 1 vCPU). rec_ram is official guidance (docs: make at least 2 GB of memory available to Docker for smoother operation, full Compose stack includes MongoDB/Meilisearch/RAG API with PostgreSQL/pgvector). rec_cpu left blank: official docs give no recommended CPU. min_disk left blank: official docs do not state a minimum disk size. GPU: official docs state LibreChat does not run AI models itself and does not need a GPU. Repo moved from danny-avila/LibreChat to LibreChat-AI/LibreChat (old URL redirects).
