FAQ

PostHog VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for PostHog?

In the RunOnVPS dataset, PostHog needs at least RAM 16 GB, CPU 4 vCPU, disk 30 GB. Our suggested starting tier, based on the recommended RAM, is the 16 GB RAM tier.

Does PostHog need a GPU?

No. PostHog does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does PostHog replace?

PostHog is catalogued here as a self-hosted alternative to PostHog Cloud / Mixpanel. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Official self-host docs (checked 2026-11-25) state the deployment needs a Hetzner-equivalent VM with 4 vCPU, 16 GB RAM and more than 30 GB storage; those are the minimum values (official). Recommended values are estimates for the hobby stack (ClickHouse, Kafka, PostgreSQL, Redis, Minio, Caddy). Self-hosting is officially unsupported with no tagged releases; install via the hobby deploy script, which generates the multi-service docker-compose stack, so no trimmed Compose snippet (same rule as Dify/Appwrite).
