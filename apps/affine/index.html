FAQ

AFFiNE VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for AFFiNE?

In the RunOnVPS dataset, AFFiNE needs at least RAM 2 GB, CPU 4 CPU cores, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does AFFiNE need a GPU?

No. AFFiNE does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does AFFiNE replace?

AFFiNE is catalogued here as a self-hosted alternative to Notion. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Official self-host docs (docs.affine.pro/self-host-affine, checked 2026-10-26): 'For basic usage, plan for at least 4 CPU cores, 2 GB RAM, and enough storage for the server, Postgres data, uploaded blobs, and configuration' — min CPU/RAM are official, no fixed disk figure so min_disk is an estimate excluding user uploads. Recommended values are estimates for a small-team stack (AFFiNE server + Postgres + Redis via official Docker Compose, the recommended install method). GitHub stars 73846 on 2026-10-26.
