Important notes

官方未标明硬件最低配置: neither the GitHub README nor docs.sftpgo.com publishes a RAM/CPU/disk minimum (checked 2026-10-24); all sizing values are conservative estimates based on the official default Docker deployment — SFTPGo is a single Go binary with an embedded data provider (bolt/SQLite by default), so its own footprint is tiny and real disk usage is driven by the files users store/transfer, which are excluded from the disk estimate. Docker: official image drakkan/sftpgo on Docker Hub and GHCR, documented on the official docs Docker page (v2.7.6 at check time). License note: dual model — the Community edition in this repo is AGPL-3.0 (copyleft), and a separate Enterprise edition is sold under a commercial license. No GPU use.
