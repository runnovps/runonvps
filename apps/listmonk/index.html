Quick start

Docker Compose quick start

A trimmed quick-start version of the official Listmonk Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  db:
    image: postgres:17-alpine
    restart: unless-stopped
    environment:
      POSTGRES_USER: ${POSTGRES_USER:-listmonk}
      POSTGRES_PASSWORD: "${POSTGRES_PASSWORD:?Set in .env}"
      POSTGRES_DB: ${POSTGRES_DB:-listmonk}
    volumes:
      - listmonk-data:/var/lib/postgresql/data
  app:
    image: listmonk/listmonk:latest
    restart: unless-stopped
    depends_on: [db]
    ports:
      - "${LISTMONK_PORT:-9000}:9000"
    environment:
      LISTMONK_app__address: 0.0.0.0:9000
      LISTMONK_app__admin_username: ${ADMIN_USERNAME:-admin}
      LISTMONK_app__admin_password: "${ADMIN_PASSWORD:?Set in .env}"
      LISTMONK_db__host: db
      LISTMONK_db__user: ${POSTGRES_USER:-listmonk}
      LISTMONK_db__password: "${POSTGRES_PASSWORD:?Set in .env}"
      LISTMONK_db__database: ${POSTGRES_DB:-listmonk}
      LISTMONK_db__ssl_mode: disable
    command: ["sh", "-c", "./listmonk --install --non-interactive --yes && ./listmonk --upgrade --yes; exec ./listmonk"]
    volumes:
      - listmonk-uploads:/listmonk/uploads
volumes:
  listmonk-data:
  listmonk-uploads:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Listmonk VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Listmonk?

In the RunOnVPS dataset, Listmonk needs at least RAM 1GB, CPU 1, disk 10GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does Listmonk need a GPU?

No. Listmonk does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Listmonk replace?

Listmonk is catalogued here as a self-hosted alternative to Mailchimp. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
