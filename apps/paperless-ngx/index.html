Quick start

Docker Compose quick start

A trimmed quick-start version of the official Paperless-ngx Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  broker:
    image: redis:7
    restart: unless-stopped
    volumes:
      - redisdata:/data
  db:
    image: postgres:17
    restart: unless-stopped
    volumes:
      - pgdata:/var/lib/postgresql/data
    environment:
      POSTGRES_DB: ${POSTGRES_DB:-paperless}
      POSTGRES_USER: ${POSTGRES_USER:-paperless}
      POSTGRES_PASSWORD: "${POSTGRES_PASSWORD:?Set in .env}"
  webserver:
    image: ghcr.io/paperless-ngx/paperless-ngx:latest
    restart: unless-stopped
    depends_on: [db, broker]
    ports:
      - "${PAPERLESS_PORT:-8000}:8000"
    volumes:
      - data:/usr/src/paperless/data
      - media:/usr/src/paperless/media
      - ./export:/usr/src/paperless/export
      - ./consume:/usr/src/paperless/consume
    environment:
      PAPERLESS_REDIS: redis://broker:6379
      PAPERLESS_DBHOST: db
      PAPERLESS_DBNAME: ${POSTGRES_DB:-paperless}
      PAPERLESS_DBUSER: ${POSTGRES_USER:-paperless}
      PAPERLESS_DBPASS: "${POSTGRES_PASSWORD:?Set in .env}"
      PAPERLESS_SECRET_KEY: "${PAPERLESS_SECRET_KEY:?Set in .env}"
      PAPERLESS_URL: ${PAPERLESS_URL:-}
volumes:
  data:
  media:
  pgdata:
  redisdata:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Paperless-ngx VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Paperless-ngx?

In the RunOnVPS dataset, Paperless-ngx needs at least RAM 2 GB, CPU 2 vCPU, disk 10 GB + archive size. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does Paperless-ngx need a GPU?

No. Paperless-ngx does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Paperless-ngx replace?

Paperless-ngx is catalogued here as a self-hosted alternative to Google Drive / Dropbox. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
