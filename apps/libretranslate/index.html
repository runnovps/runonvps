Quick start

Docker Compose quick start

A trimmed quick-start version of the official LibreTranslate Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
# Official single-container image; port 5000. Optional LT_LOAD_ONLY limits loaded languages.
services:
  libretranslate:
    image: libretranslate/libretranslate:latest
    restart: unless-stopped
    ports:
      - "5000:5000"
    volumes:
      - libretranslate_models:/home/libretranslate/.local:rw
    # environment:
    #   - LT_LOAD_ONLY=en,es,fr,de
    #   - LT_API_KEYS=true

volumes:
  libretranslate_models:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

LibreTranslate VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for LibreTranslate?

In the RunOnVPS dataset, LibreTranslate needs at least RAM 2 GB, CPU 1 vCPU, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does LibreTranslate need a GPU?

No. LibreTranslate does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does LibreTranslate replace?

LibreTranslate is catalogued here as a self-hosted alternative to Google Translate / DeepL. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
