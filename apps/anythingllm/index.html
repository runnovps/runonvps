Quick start

Docker Compose quick start

A trimmed quick-start version of the official AnythingLLM Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  anythingllm:
    image: mintplexlabs/anythingllm
    restart: unless-stopped
    ports:
      - "3001:3001"
    cap_add: [SYS_ADMIN]
    environment:
      - STORAGE_DIR=/app/server/storage
    volumes:
      - ${STORAGE_LOCATION:-./anythingllm}:/app/server/storage
      - ${STORAGE_LOCATION:-./anythingllm}/.env:/app/server/.env

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

AnythingLLM VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for AnythingLLM?

In the RunOnVPS dataset, AnythingLLM needs at least RAM 2 GB, disk 10 GB. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does AnythingLLM need a GPU?

Not for the baseline deployment. A GPU is optional for AnythingLLM and only helps specific workloads — see the source notes on this page.

What SaaS product does AnythingLLM replace?

AnythingLLM is catalogued here as a self-hosted alternative to ChatGPT. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Recommended values are estimates. GPU optional: the built-in local LLM engine can run on CPU or GPU (CUDA/Vulkan); cloud LLM providers need no GPU. Official Docker image: mintplexlabs/anythingllm.
