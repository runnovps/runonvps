Important notes

Minimum RAM/disk are official, from the repo BARE_METAL.md Minimum Requirements section (aim for at least 2GB RAM; minimum 10GB disk recommended) - that file covers the non-Docker production method, and no separate hardware minimum was found in the repo's Docker docs. min_cpu left blank: official docs do not state a CPU minimum. Recommended values are estimates. GPU optional: the built-in local LLM engine can run on CPU or GPU (CUDA/Vulkan); cloud LLM providers need no GPU. Official Docker image: mintplexlabs/anythingllm.
