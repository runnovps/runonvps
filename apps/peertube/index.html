Quick start

Docker Compose quick start

A trimmed quick-start version of the official PeerTube Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  peertube:
    image: chocobozzz/peertube:production
    restart: always
    env_file: [.env]
    ports:
      - "9000:9000"
    volumes:
      - ./data:/data
      - ./config:/config
    depends_on: [postgres, redis]
  postgres:
    image: postgres:17-alpine
    restart: always
    env_file: [.env]
    volumes:
      - ./db:/var/lib/postgresql/data
  redis:
    image: redis:8-alpine
    restart: always
    volumes:
      - ./redis:/data

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

PeerTube VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for PeerTube?

In the RunOnVPS dataset, PeerTube needs at least RAM 1.5 GB, CPU 1 vCPU, disk 20 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does PeerTube need a GPU?

No. PeerTube does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does PeerTube replace?

PeerTube is catalogued here as a self-hosted alternative to YouTube. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Source check

Important notes

Official FAQ (checked 2026-11-12) minimum: 1 vCore, 1.5 GB RAM, enough storage for videos; recommended for 1,000 concurrent viewers: 4 vCore, 4 GB RAM (8 vCore/8 GB if transcoding on the same machine); the FAQ gives no fixed disk number, so the disk value is an estimate. Official Docker stack chocobozzz/peertube:production + PostgreSQL 17 + Redis 8, web UI on port 9000 (fronted by the bundled nginx on 80/443), /data + /config volumes; full official deployment also needs the nginx webserver/certbot services and the official .env. GitHub stars 15398 on 2026-11-12.
