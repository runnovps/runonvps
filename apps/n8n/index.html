Quick start

Docker Compose quick start

A trimmed quick-start version of the official n8n Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  n8n:
    image: docker.n8n.io/n8nio/n8n:latest
    restart: unless-stopped
    ports:
      - "${N8N_PORT:-5678}:5678"
    environment:
      GENERIC_TIMEZONE: ${GENERIC_TIMEZONE:-UTC}
      TZ: ${TZ:-UTC}
      N8N_ENCRYPTION_KEY: ${N8N_ENCRYPTION_KEY:-}
      WEBHOOK_URL: ${WEBHOOK_URL:-}
    volumes:
      - n8n_data:/home/node/.n8n

volumes:
  n8n_data:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

n8n VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for n8n?

In the RunOnVPS dataset, n8n needs at least RAM 2 GB, CPU 1 vCPU, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does n8n need a GPU?

No. n8n does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does n8n replace?

n8n is catalogued here as a self-hosted alternative to Zapier / Make. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
