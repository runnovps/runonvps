Quick start

Docker Compose quick start

A trimmed quick-start version of the official Mastodon Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  db:
    image: postgres:14-alpine
    restart: unless-stopped
    shm_size: 256mb
    networks: [internal_network]
    volumes:
      - ./postgres14:/var/lib/postgresql/data
    environment:
      - POSTGRES_HOST_AUTH_METHOD=trust
  redis:
    image: redis:7-alpine
    restart: unless-stopped
    networks: [internal_network]
    volumes:
      - ./redis:/data
  web:
    image: ghcr.io/mastodon/mastodon:v4.7.3
    restart: unless-stopped
    env_file: .env.production
    command: bundle exec puma -C config/puma.rb
    networks: [external_network, internal_network]
    ports:
      - '127.0.0.1:3000:3000'
    depends_on: [db, redis]
    volumes:
      - ./public/system:/mastodon/public/system
  streaming:
    image: ghcr.io/mastodon/mastodon-streaming:v4.7.3
    restart: unless-stopped
    env_file: .env.production
    command: node ./streaming/index.js
    networks: [external_network, internal_network]
    ports:
      - '127.0.0.1:4000:4000'
    depends_on: [db, redis]
  sidekiq:
    image: ghcr.io/mastodon/mastodon:v4.7.3
    restart: unless-stopped
    env_file: .env.production
    command: bundle exec sidekiq
    networks: [external_network, internal_network]
    depends_on: [db, redis]
    volumes:
      - ./public/system:/mastodon/public/system
networks:
  external_network:
  internal_network:
    internal: true

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Mastodon VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Mastodon?

In the RunOnVPS dataset, Mastodon needs at least RAM 2GB, CPU 2, disk 20GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does Mastodon need a GPU?

No. Mastodon does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Mastodon replace?

Mastodon is catalogued here as a self-hosted alternative to X (Twitter). Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.
