Important notes

最低配置为官方数字: the official Self Host (Docker Compose) docs state 'At least 2 vCPU and 4 GB RAM' (checked 2026-10-24). Official docs give no disk minimum, so min_disk is a conservative estimate for the 4-container stack (app/worker/PostgreSQL/Redis images plus database growth). Recommended values are estimates for a small team; the official Production Setup doc instead sizes components separately (App 1 vCPU/1 GB, Worker 0.5 vCPU/1 GB per concurrent flow, managed Postgres 2 vCPU/4 GB, Redis 1 vCPU/1 GB, S3 required). Docker: official Docker Compose install is the recommended path; a single-container hobby install (embedded PGLite + in-memory Redis) also exists. License anomaly: the repo LICENSE file puts everything outside packages/ee/ under 'MIT Expat', with the ee portions under a separate Activepieces enterprise license — GitHub's API therefore reports the license as NOASSERTION.
