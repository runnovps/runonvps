Quick start

Docker Compose quick start

A trimmed quick-start version of the official Emby Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  emby:
    image: emby/embyserver:latest
    restart: unless-stopped
    ports:
      - "8096:8096"
      - "8920:8920"
    environment:
      TZ: ${TZ:-UTC}
    volumes:
      - ./data/config:/config
      - ./media:/mnt/share1

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Emby VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Emby?

In the RunOnVPS dataset, Emby needs at least RAM 512 MB, CPU 1 vCPU, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 2 GB RAM tier.

Does Emby need a GPU?

Not for the baseline deployment. A GPU is optional for Emby and only helps specific workloads — see the source notes on this page.

What SaaS product does Emby replace?

Emby is catalogued here as a self-hosted alternative to Plex. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Source check

Important notes

Official System Requirements page (checked 2026-11-18): minimum without transcoding is an Intel Core 2 Duo 1.6 GHz or better with at least 512 MB RAM on Linux (1 GB on Windows/Mac); recommended for transcoding HD content is a Core 2 Duo 2.4 GHz or better with at least 2 GB RAM. Official guidance is model-class, so vCPU counts are estimates. Disk is an estimate: app + metadata footprint only, media library excluded (official docs give no disk figure). GPU optional: hardware transcoding is supported with a GPU and needs Emby Premiere. Official Docker image emby/embyserver (Docker Hub), web UI on 8096 (8920 HTTPS), /config volume plus media mounts. Proprietary software: no GitHub repo/stars, project site linked instead.
