Quick start

Docker Compose quick start

A trimmed quick-start version of the official Nextcloud Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  db:
    image: mariadb:10.11
    restart: unless-stopped
    command: --transaction-isolation=READ-COMMITTED --log-bin=binlog --binlog-format=ROW
    volumes:
      - db:/var/lib/mysql
    environment:
      MYSQL_ROOT_PASSWORD: "${MYSQL_ROOT_PASSWORD:?Set in .env}"
      MYSQL_PASSWORD: "${MYSQL_PASSWORD:?Set in .env}"
      MYSQL_DATABASE: ${MYSQL_DATABASE:-nextcloud}
      MYSQL_USER: ${MYSQL_USER:-nextcloud}
  app:
    image: nextcloud:latest
    restart: unless-stopped
    ports:
      - "${NEXTCLOUD_PORT:-8080}:80"
    depends_on: [db]
    volumes:
      - nextcloud:/var/www/html
    environment:
      MYSQL_HOST: db
      MYSQL_PASSWORD: "${MYSQL_PASSWORD:?Set in .env}"
      MYSQL_DATABASE: ${MYSQL_DATABASE:-nextcloud}
      MYSQL_USER: ${MYSQL_USER:-nextcloud}
volumes:
  db:
  nextcloud:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Nextcloud VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Nextcloud?

In the RunOnVPS dataset, Nextcloud needs at least RAM 2GB, CPU 2, disk 10GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does Nextcloud need a GPU?

No. Nextcloud does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Nextcloud replace?

Nextcloud is catalogued here as a self-hosted alternative to Google Workspace (Drive). Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Stars/license checked 2026-10-24 on the GitHub repo page (nextcloud/server). The official admin manual does not publish a whole-machine minimum — 官方未标明整机配置: it only specifies memory per PHP process (minimum 128MB, recommended 512MB per process; the official AIO deployment defaults to a max of 512MB RAM per PHP process). Estimates are based on the official Docker / All-in-One deployment (Nextcloud + PostgreSQL + Redis); real requirements scale strongly with user count, enabled apps and file volume, and user files are excluded from min_disk.

Data source: https://docs.nextcloud.com/server/latest/admin_manual/installation/system_requirements.html
