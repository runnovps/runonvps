Quick start

Docker Compose quick start

A trimmed quick-start version of the official Mautic Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
# Official image; web + cron + worker roles share one image via DOCKER_MAUTIC_ROLE.
services:
  mautic_web:
    image: mautic/mautic:latest
    restart: unless-stopped
    ports:
      - "8080:80"
    environment:
      MAUTIC_DB_HOST: db
      MAUTIC_DB_DATABASE: mautic
      MAUTIC_DB_USER: mautic
MAUTIC_DB_PASSWORD: <redacted>
      DOCKER_MAUTIC_ROLE: mautic_web
    depends_on:
      - db
    volumes:
      - mautic_data:/var/www/html
  mautic_cron:
    image: mautic/mautic:latest
    restart: unless-stopped
    environment:
      MAUTIC_DB_HOST: db
      MAUTIC_DB_DATABASE: mautic
      MAUTIC_DB_USER: mautic
MAUTIC_DB_PASSWORD: <redacted>
      DOCKER_MAUTIC_ROLE: mautic_cron
    depends_on:
      - mautic_web
    volumes:
      - mautic_data:/var/www/html
  db:
    image: mysql:8.4
    restart: unless-stopped
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_general_ci
    environment:
MYSQL_ROOT_PASSWORD: <redacted>
      MYSQL_DATABASE: mautic
      MYSQL_USER: mautic
MYSQL_PASSWORD: <redacted>
    volumes:
      - db_data:/var/lib/mysql
volumes:
  mautic_data:
  db_data:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Mautic VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Mautic?

In the RunOnVPS dataset, Mautic needs at least RAM 2 GB, CPU 1 vCPU, disk 10 GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 4 GB RAM tier.

Does Mautic need a GPU?

No. Mautic does not need a GPU — the baseline deployment runs on CPU only.

What SaaS product does Mautic replace?

Mautic is catalogued here as a self-hosted alternative to HubSpot / Mailchimp. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Important notes

Official requirements for Mautic 7 (checked 2026-11-26): PHP 8.2-8.5, MySQL 8.4+ or MariaDB 10.11+ with InnoDB; no official RAM/CPU/disk minimum, all sizing values are estimates for the official Docker deployment (mautic/mautic image, web + cron + worker roles via DOCKER_MAUTIC_ROLE, port 80, MySQL required, cron jobs drive campaigns and segments).
