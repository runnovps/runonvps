Quick start

Docker Compose quick start

A trimmed quick-start version of the official Immich Docker deployment — same images and services, comments and extras removed. Every secret is an .env placeholder.

docker-compose.ymlquick-start version
services:
  immich-server:
    image: ghcr.io/immich-app/immich-server:${IMMICH_VERSION:-release}
    volumes:
      - ${UPLOAD_LOCATION:-./library}:/data
    env_file: [.env]
    ports:
      - "2283:2283"
    depends_on: [redis, database]
    restart: unless-stopped
  immich-machine-learning:
    image: ghcr.io/immich-app/immich-machine-learning:${IMMICH_VERSION:-release}
    volumes:
      - model-cache:/cache
    env_file: [.env]
    restart: unless-stopped
  redis:
    image: docker.io/valkey/valkey:9
    restart: unless-stopped
  database:
    image: ghcr.io/immich-app/postgres:14-vectorchord0.4.3-pgvectors0.2.0
    environment:
      POSTGRES_PASSWORD: "${DB_PASSWORD:?Set DB_PASSWORD in .env}"
      POSTGRES_USER: ${DB_USERNAME:-postgres}
      POSTGRES_DB: ${DB_DATABASE_NAME:-immich}
    volumes:
      - ${DB_DATA_LOCATION:-./postgres}:/var/lib/postgresql/data
    restart: unless-stopped
volumes:
  model-cache:

Save it as docker-compose.yml, put the ${...} values in a .env file next to it, then run docker compose up -d. The Self-host Starter Pack versions (20 apps) add per-app setup notes, backup pointers and hardening checks.

FAQ

Immich VPS questions

Answers use only the checked dataset on this page — estimates are called out as estimates.

What are the minimum VPS requirements for Immich?

In the RunOnVPS dataset, Immich needs at least RAM 6GB, CPU 2, disk 20GB. Some of these figures are estimated rather than officially published — the badge next to each value in the table above shows its basis. Our suggested starting tier, based on the recommended RAM, is the 8 GB RAM tier.

Does Immich need a GPU?

Not for the baseline deployment. A GPU is optional for Immich and only helps specific workloads — see the source notes on this page.

What SaaS product does Immich replace?

Immich is catalogued here as a self-hosted alternative to Google Photos. Self-hosting replaces the hosted subscription with your own VPS; feature parity varies, so compare your required workflow before migrating.

Source check

Important notes

Stars/license checked 2026-10-24 on the GitHub repo page. Official Requirements page: RAM minimum 6GB / recommended 8GB, CPU minimum 2 cores / recommended 4 cores — min/rec are official. Official docs give no fixed disk size: the Postgres database is typically 1-3GB and must be on local SSD (network shares unsupported), and thumbnails/transcoded video add about 10-20% on top of the photo library, so min_disk is an estimate excluding the media library itself. Since v3 the machine-learning container on amd64 requires x86-64-v2. GPU is optional (hardware transcoding/ML acceleration); it also runs CPU-only, and with 4GB RAM if ML features are disabled. Docker Compose is the required install method per official docs.
